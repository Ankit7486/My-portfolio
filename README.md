# Ankit Raj — Portfolio

A modern, responsive developer portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use:
```bash
npx serve .
```

## Deploy
Push the repository to GitHub and enable GitHub Pages from **Settings → Pages**.

## Customize
- Replace project cards with verified live projects and GitHub links.
- Add your resume PDF as `assets/Ankit-Raj-Resume.pdf` and connect the Resume button.
- Replace Instagram/X `#` links with your actual profiles.
